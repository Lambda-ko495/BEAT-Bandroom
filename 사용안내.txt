BEAT Bandroom 3 사용 안내

1. BEAT-Bandroom.html을 Chrome 또는 Edge에서 여세요.
2. 음원을 선택하고 전체 곡 분석이 끝날 때까지 기다리세요.
3. 스타일, 효과 강도, 목표 음량, 피크 보호 설정을 고르세요.
4. '이 설정으로 마스터 만들기'를 누르세요.
5. 처리 전후 결과를 확인하고 원본/마스터를 비교한 뒤 WAV로 저장하세요.

추가 기능
자동 추천 사용법
- 음원을 올린 후 자동 추천 방향을 자연스럽게/부드럽게/선명하게 중에서 고르세요.
- 자동 설정 추천을 누르면 저역과 고역 비중, 피크 여유, 음량과 강약 차이를 분석합니다.
- 추천 설정과 이유를 확인한 뒤 설정만 적용하거나 적용하고 마스터 만들기를 누르세요.
- EQ 보정은 대체로 0.5~1 dB, 추가 압축은 최대 25%, 효과 강도는 60~70%로 보수적으로 제안합니다.
- 목표 음량과 피크 상한은 현재 값을 유지하며 스테레오 폭은 100%, 피크 보호는 켬으로 제안합니다.
- 추천을 만드는 것만으로 기존 설정이나 처리본이 바뀌지 않습니다. 적용은 한 단계로 되돌릴 수 있습니다.
- 새 음원을 올리거나 방향/목표/피크 상한을 바꾸면 추천을 다시 만드세요.
- 오디오 특성에 대한 규칙 기반 추천입니다. 장르/보컬/악기를 인식하거나 잡음을 제거하는 AI 기능은 아닙니다.
- 듣기 좋은 음색은 취향과 곡에 따라 다르므로 같은 음량으로 비교해 보세요.

- 효과 강도: 0~100%로 음색·고음 완화·다이내믹 정돈 효과를 원본과 섞습니다.
  0%에서도 목표 음량과 피크 보호는 별도로 적용됩니다.
- 결과 요약: 전체 음량, True Peak 추정값, 고역 비중, 피크와 평균 음량의 차이,
  효과 강도와 리미터 감쇄량을 표시합니다. 수치만으로 청감 개선을 판단하지 않습니다.
- 비교 구간: 시작·끝을 분:초(예: 0:30.5) 또는 초로 입력한 뒤 '이 구간 반복'을 누르세요.
  재생 중 현재 위치를 시작/끝으로 지정하거나 파형을 드래그해도 됩니다.
  0.3초 이상 선택해야 하며, 같은 구간이 원본과 마스터에 적용됩니다.
  비교 구간은 미리 듣기에만 적용하며 WAV는 곡 전체로 출력합니다.
- 되돌리기/다시 실행: 설정 변경을 최대 60개 상태까지 보관합니다.
  Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y를 지원합니다(입력 필드 밖에서).
  슬라이더 한 번의 조절은 한 단계로 저장합니다. 음원·재생 위치·구간은 이력에 포함하지 않습니다.
  이전 설정을 복원한 뒤에는 마스터를 다시 만들어야 합니다.
- True Peak: 4배 FIR 보간으로 샘플 사이의 피크를 추정합니다.
  공인 인증 계측기는 아니며, 별도의 전문 계측기와 오차가 있을 수 있습니다.
- 리미터: 스테레오 연동, 5 ms 미리 보기, 80 ms 복귀시간으로 순간 피크를 제어합니다.
  처리 후 True Peak를 다시 측정하고 필요하면 전체 음량을 조금 더 낮춥니다.
  설정한 상한보다 0.05 dB 낮게 처리해 여유를 둡니다.
  약 6 dB의 리미팅 한도 때문에 목표 LUFS에 도달하지 못할 수 있습니다.
  리미터를 꺼도 전체 음량을 낮추는 방식으로 피크를 보호합니다.

기존 기능
- 원본은 보라색, 마스터는 핑크색과 체크 표시로 선택 상태를 구분합니다.
- 비교 음량 맞추기는 미리 듣기에만 적용합니다.
- 현재 설정 한 개를 브라우저에 저장할 수 있습니다.
  이전 버전에서 저장한 설정도 새 항목에 기본값을 적용해 불러옵니다.
- 이미지를 포함한 단일 HTML로 설치 및 인터넷 연결 없이 실행합니다.
- 모든 오디오 처리는 브라우저 안에서 이루어지며 외부로 전송하지 않습니다.
- 모노/스테레오, 최대 150 MB, 16/24비트 PCM WAV 출력을 지원합니다.
- 디코딩 과정에서 브라우저의 오디오 처리 샘플레이트로 변환될 수 있습니다.
- WAV에는 양자화 디더가 적용됩니다. 원본 파일은 수정하지 않습니다.
- True Peak 분석과 재검증 때문에 이전 버전보다 처리 시간이 늘어날 수 있습니다.
- 고음 완화는 EQ이며 AI 잡음 제거 기능은 아닙니다.

검증
기준 신호, 샘플 사이 피크가 큰 신호, 설정 이력, 효과 혼합, 구간 유효성,
이전 저장 설정 호환, WAV 재디코딩, 무음 및 잘못된 파일 처리를 검사했습니다.
원본 Tavern Rain 음원으로 전체 처리도 점검했습니다.
실제 음악의 청감 평가는 음량을 맞춘 원본/마스터 비교로 진행해 주세요.
