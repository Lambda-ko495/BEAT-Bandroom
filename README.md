# BEAT Bandroom

**Suno로 만든 음악의 거슬리는 고역을 완화하고, 브라우저에서 음색과 음량을 정돈하는 개인용 오디오 도구입니다.**

[English](README.en.md)

## 만든 이유

저는 음악을 듣는 것을 좋아하지만, 작사나 작곡에 대해서는 잘 모릅니다. 음악 제작의 전문 지식 없이도 직접 느낀 불편을 해결해 보고 싶어, 원하는 기능을 말로 설명하고 AI의 도움으로 구현하는 바이브 코딩 방식을 선택했습니다.

음악 듣는 것을 좋아하는 저에게 Suno AI는 정말 좋은 서비스입니다. 다만 제가 사용해 본 범위에서는 어떤 프롬프트를 사용하더라도 특유의 노이즈가 충분히 해결되지 않았습니다. 좋아하는 음악을 조금 더 편안하게 듣고 싶다는 마음이 이 프로그램을 만드는 계기가 됐습니다.

Suno AI로 음악을 만들면서 일부 음원에서 지글거리는 소리, 날카롭게 쏘는 고음처럼 노이즈로 느껴지는 부분이 신경 쓰였습니다. 이런 소리를 줄이고 음악을 조금 더 편안하게 듣고 싶어 AI와 대화하며 코드를 작성하고 개선하는 **바이브 코딩**으로 이 프로젝트를 만들었습니다.

출발점은 ‘Suno AI 특유의 노이즈를 줄여 보자’였습니다. 개발 과정에서는 구현한 기능의 범위를 분명히 했습니다. 현재 버전은 노이즈를 찾아 분리하는 전용 복원 도구가 아니라, **고역 완화·EQ·다이내믹 조절·음량 보정**을 통해 거슬림을 줄이는 마스터링 보조 도구입니다.

설치나 서버 업로드 없이 사용할 수 있도록 이미지와 코드를 하나의 HTML 파일에 담았습니다. 원본과 처리본을 같은 구간에서 비교하고, 마음에 드는 결과를 WAV로 저장할 수 있습니다.

## 오디오 용어 쉽게 이해하기

| 용어 | 쉬운 설명 | 이 프로그램에서 하는 일 |
| --- | --- | --- |
| **고역 완화** | 소리의 높은 음역을 조금 줄여, 날카롭거나 쏘는 느낌을 덜어 주는 것입니다. | 고음 완화 설정으로 높은 주파수 대역을 낮춥니다. 거슬림이 줄 수 있지만, 너무 많이 적용하면 소리가 답답해질 수 있습니다. 특정 잡음만 골라 제거하는 기능은 아닙니다. |
| **EQ(이퀄라이저)** | 저음·중음·고음의 크기를 각각 조절해 전체 음색을 바꾸는 도구입니다. | 저음을 조절해 무게감을, 중음을 조절해 보컬·악기의 존재감을, 고음을 조절해 밝기와 선명함을 다듬습니다. 실제 변화는 곡에 따라 다릅니다. |
| **다이내믹 조절** | 음악에서 큰 소리와 작은 소리 사이의 강약 차이를 조절하는 것입니다. | ‘다이내믹 정돈’은 큰 소리를 상대적으로 눌러 강약 차이를 줄이는 압축 처리입니다. 더 고르게 들릴 수 있지만, 과하면 생동감이나 타격감이 줄어들 수 있습니다. |
| **음량 보정** | 곡 전체가 어느 정도 크게 들리는지 측정하고, 선택한 목표에 맞춰 크기를 조절하는 것입니다. | LUFS라는 음량 지표를 기준으로 곡을 키우거나 줄입니다. 피크 보호 때문에 목표보다 작게 완성될 수도 있으며, 음량 증가 자체가 음질 향상을 뜻하지는 않습니다. |

예를 들어, 고음이 거슬리고 전체 소리는 작은 곡이라면 **고역 완화로 자극을 줄이고, EQ로 음색을 다듬은 다음, 필요한 만큼 다이내믹을 정돈하고 음량을 맞추는 방식**으로 사용할 수 있습니다. 모든 곡에 네 가지 처리를 강하게 적용할 필요는 없습니다.

## 주요 기능

- **기기 안에서 처리:** 오디오를 외부 서버로 전송하지 않습니다.
- **음원 분석:** 곡 전체 음량(LUFS), 샘플 피크, True Peak 추정값을 표시합니다.
- **네 가지 스타일:** 클린 기타, 웜 보컬, 펀치 드럼, 에어 베이스를 제공합니다.
- **세부 조절:** 저음·중음·고음 EQ, 고음 완화, 스테레오 폭, 다이내믹 정돈을 조절합니다.
- **효과 강도:** 음색·압축 효과를 원본과 0~100%로 섞습니다. 목표 음량과 피크 보호는 별도로 적용합니다.
- **자동 추천:** 자연스럽게·부드럽게·선명하게 중 방향을 고르면 음량, 피크 여유, 저역·고역 비중 등을 바탕으로 보수적인 설정과 이유를 제안합니다.
- **자동 적용 및 생성:** 추천 설정만 적용하거나, 적용부터 마스터 생성까지 이어서 실행합니다.
- **원본/마스터 비교:** 비교 음량 보정과 동일 구간 반복을 지원합니다.
- **비교 구간 지정:** 파형 드래그, 시작·끝 시간 입력, 현재 재생 위치 지정이 가능합니다.
- **되돌리기·다시 실행:** 설정 변경을 복원합니다. 자동 추천 적용도 한 단계로 되돌립니다.
- **피크 보호:** 4배 FIR 보간 기반 True Peak 추정과 스테레오 연동 리미터를 사용하고, 처리 후 재측정합니다.
- **처리 결과 요약:** 음량, 피크, 고역 비중, 피크와 평균 음량 차이의 변화를 보여줍니다.
- **설정 저장:** 현재 설정 한 개를 브라우저에 저장하고 다시 불러옵니다.
- **WAV 출력:** 16비트 또는 24비트 PCM WAV로 저장합니다.

## 사용 방법

1. `BEAT-Bandroom.html`을 내려받아 Chrome 또는 Edge에서 엽니다.
2. 오디오 파일을 선택하고 전체 곡 분석을 기다립니다.
3. 자동 추천을 사용하거나 스타일과 세부 설정을 직접 선택합니다.
4. **이 설정으로 마스터 만들기** 또는 **적용하고 마스터 만들기**를 누릅니다.
5. 원본과 마스터를 음량을 맞춘 상태로 비교합니다.
6. 마음에 들면 WAV로 저장합니다.

설정이 바뀌면 마스터를 다시 생성해야 합니다. 구간 반복과 비교 음량 보정은 미리 듣기에만 적용되며, WAV에는 곡 전체가 출력됩니다.

### 지원 범위

- 모노 또는 스테레오 오디오
- WAV·MP3 등 브라우저가 디코딩할 수 있는 형식
- 파일당 최대 150 MB, 10분 이하 권장
- 인터넷 연결 없이 실행 가능한 단일 HTML

긴 파일은 처리 시간과 메모리 사용이 늘어납니다. 디코딩 과정에서 브라우저의 오디오 처리 샘플레이트로 변환될 수 있습니다. 원본 파일은 수정하지 않습니다.

## 개발 및 테스트

AI의 코딩 지원을 받아 기능을 구현하고, 브라우저에서 동작을 확인하며 수정했습니다. 아래는 개발 중 수행한 검증 결과입니다. 공인 품질 인증이나 모든 음원에 대한 보증을 뜻하지 않습니다.

### 기능 검사

최종 자동 추천 버전에서 **45개 검사 항목을 통과**했습니다. 주요 항목은 다음과 같습니다.

- 기준 신호의 음량 측정과 목표 음량 보정
- 샘플 사이 피크 감지 및 리미터의 피크 보호
- 효과 강도 0%에서 음색·압축 처리 전 원본 유지
- 원본/마스터 비교 구간 입력과 유효성 검사
- 설정 변경, 되돌리기·다시 실행, 이전 저장 설정 호환
- 자동 추천의 설정 보존, 적용, 생성, 한 단계 되돌리기
- 16/24비트 WAV 생성 및 재디코딩
- 무음과 잘못된 파일 처리

### 실제 음악으로 확인

**Tavern Rain**

곡 듣기: [YouTube](https://youtu.be/kMuIO5EZWfI?si=LhqyX5A8S7zipIyI)

개발 과정에서 원본과 처리본을 비교했고, 자동 추천 버전에서도 전체 곡 처리를 확인했습니다. ‘부드럽게’ 자동 추천 시험에서는 다음 결과를 얻었습니다.

- 원본 약 -15.43 LUFS → 처리본 -14.00 LUFS
- 처리본 True Peak 추정값 약 -1.86 dBTP
- 피크와 평균 음량의 차이 약 14.0 dB로 대체로 유지

이는 프로그램의 분석값입니다. 실제로 들어본 사용자는 초기 처리본이 원본보다 조금 더 부드럽게 느껴진다고 평가했습니다. 개인의 청감 평가이며 모든 곡에 적용되는 결과는 아닙니다.

**Dreamy Celestial Healing**

곡 듣기: [YouTube](https://youtu.be/5ac6fhs1AkY)

사용자가 만든 완성본과 원본을 프로그램과 별개인 **FFmpeg**로 비교했습니다.

| 항목 | 원본 MP3 | 처리본 WAV |
| --- | ---: | ---: |
| 전체 음량 | -15.5 LUFS | -14.0 LUFS |
| True Peak | 약 -4.1 dBTP | 약 -2.6 dBTP |
| 음량 변화 범위(LRA) | 3.6 LU | 3.6 LU |
| 디코딩된 재생 길이 | 179.96초 | 179.96초 |
| 0 dBFS에 도달하거나 초과한 샘플 | 없음 | 없음 |

출력은 **24비트·48kHz·스테레오**였으며, 원본과 샘플 수가 같고 파형의 시간 밀림이 없었습니다. 검사상 1초 구간 단위의 중간 누락도 발견되지 않았습니다. 변화의 대부분은 약 1.53 dB의 음량 증가였으며, 원본의 강약과 파형은 대체로 유지됐습니다.

이 결과는 해당 음원에서 음량 보정과 파일 출력이 정상 작동했다는 근거입니다. 리미터의 모든 동작이나 모든 장르에서의 청감 개선을 증명하는 결과는 아닙니다.

## 한계와 참고 사항

- 고음 완화는 EQ 처리입니다. 특정 잡음의 분리·제거, 스템 분리, 보컬 복원 기능은 없습니다.
- 자동 추천은 오디오 수치에 기반한 규칙 방식입니다. 장르·악기·보컬을 인식하는 AI 모델을 사용하지 않습니다.
- True Peak는 4배 보간 추정값입니다. 공인 계측기 인증 제품이 아니며 전문 측정 도구와 차이가 있을 수 있습니다.
- 피크 보호와 리미팅 한도 때문에 선택한 목표 음량에 도달하지 못할 수 있습니다.
- 이미 손실되거나 심하게 왜곡된 소리를 원래대로 복원하지 못합니다. MP3를 24비트 WAV로 저장해도 손실된 정보가 복원되지는 않습니다.
- 음량이 커진 것을 음질 개선으로 판단하지 않도록 원본과 비교 음량을 맞춰 들어보세요.
- 공개 전용 테스트 음원을 제외한 개인 음원은 저장소에 포함할 필요가 없습니다. 사용하거나 공유하는 음원과 이미지의 권리를 확인해 주세요.

## 프로젝트 성격

### 이미지 제작

프로그램의 UI에 사용된 캐릭터 이미지는 Midjourney로 생성했습니다.

이 프로젝트는 개인적인 불편을 해결하기 위해 AI와 함께 만든 소규모 오디오 도구입니다. 전문 마스터링이나 음원 복원을 대체한다고 주장하지 않습니다. Suno와 제휴하거나 공식 지원을 받는 프로젝트가 아닙니다.

불편한 고음을 조금 줄이고, 원래 음악의 분위기를 살리면서 듣기 편한 결과를 만드는 것이 목표입니다.
